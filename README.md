One line, under 200 characters: the excuse a hardware wallet gives for refusing to sign a transaction at 3 AM. The wallet remembers the last bad 3 AM decision — rent money swapped for a dog coin — keeps the receipt, and defers the verdict to sunrise.

> The last time you woke me at 3 AM, you swapped rent money for a dog coin. I still keep the receipt. Ask me at sunrise.

## Run it

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (118 characters, UTF-8).
